# 经营报告 HTML 样式说明

本报告样式面向门店经营复盘场景：第一屏展示报告名称、数据窗口与来源边界，正文按「来源与覆盖、通知、KPI、门店、渠道、餐段、档口、产品」的顺序组织。

设计约束：

- HTML 必须自包含，样式、数据和轻量交互脚本均内嵌在单个文件中。
- 不加载网络脚本、字体、图片或样式表。
- 所有图表模块必须保留可访问表格兜底，表格包含 `caption`、列标题和 `aria-label`。
- 缺少可选模块时保留对应章节，并以可见通知说明数据边界。
- 来源区展示报告窗口、注册表版本、覆盖来源和查询任务线索，不展示原始表格路径。
- 月会报告只覆盖经营、趋势、渠道、餐段、档口与产品模块。
